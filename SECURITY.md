# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 1.0.x   | Yes       |

## Reporting a Vulnerability

Do **not** open a public issue. Send details to the maintainer privately:

- Email: [contact@faisalaffan.com](mailto:contact@faisalaffan.com)

Response within 48 hours. Once resolved, a security advisory will be published.
